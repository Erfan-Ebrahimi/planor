# Components

The inventory follows the surfaces where users encounter each control. Permissions and feature flags can hide an action or leave a read-only display. Disabled or pending records must not be treated as interactive simply because their content is visible.

## Shared controls

| Element | Variants and behavior | Source directory under `client/src/components/Utils/` |
| --- | --- | --- |
| Button | Default, bordered, icon base/icon/centered/icon with text, no background, login, submit, cancel, popup/context and header/logo. State comes from active, hover, focus, disabled and permission. | `Button/` |
| Input and form | Standard, full-width and auth inputs. Password appearance and strength option, numeric masking where used, optional error styling and form submission behavior. Textareas autosize within caller row limits. | `Input/`, `TextArea/`, `Form/` |
| Dropdown | Default/full-width, selectable menu, open/closed indicator, optional searchable prefix, active/selected and disabled states. Mouse or keyboard choices. | `Dropdown/` |
| Selection and progress | Checkboxes at 14/20px and radios at 10/12px, checked/unchecked with disabled treatment where provided. Tiny progress used for password strength. | `Checkbox/`, `Radio/`, `ProgressBar/` |
| Icon and loader | SVG icons at 8/10/12/13/14/16/18/20px, plus locale flags. Small, normal and massive loaders mark pending rendering. | `Icon/`, `Loader/` |
| Popup primitives | Anchored shell, header/back, separator, content widths and close. Viewport popup supports success/error with optional auto-dismiss. Centered modal locks background scroll. | `Popup/`, `PopupElements/`, `ViewportPopup/`, `Modal/` |
| Message | Warning and error variants with optional dismiss. | `Message/` |
| File and link helpers | Native file chooser with accepted type, optional multiple selection. Separate external links and renderer for clickable URL/mention text. | `FilePicker/`, `ExternalLink/`, `LinkifiedTextRenderer/` |
| Editor and preview | Markdown toolbar, preview/sanitized rendering, external link treatment and mention overlay. | `Markdown/`, `Mention/`, `MentionMDEditor/`, `MentionOverlay/`, `MentionTextArea/` |
| Table family | Default/compact table, headings, body, resize handles, pagination, column visibility, fit/sort reset. Renderers include basic text, boolean, radio, date, color, user, image, Markdown and settings controls. Interactive cells suppress parent row actions as appropriate. | `Table/`, including `ActionsHeader/`, `ColumnSelectPopup/` and cell folders |

The board table shows notifications, completion, name, labels, members, list, description indicator, attachment and comment counts, due and closest due dates, timer, tasks and actions by default. The cover, full description and created/updated actor/time columns start hidden. The footer offers 25, 50, 100, 250, 500, 1,000 or all rows per page. Sources: `client/src/components/Board/ListView/ListView.jsx`, `client/src/components/Utils/Table/TablePagination.jsx`.
